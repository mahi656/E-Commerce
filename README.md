# Next Store - Premium E-Commerce

An ultra-premium E-commerce platform with a modern AI-professional aesthetic.

## 🚀 Quick Deployment (Docker)

To deploy the entire stack (Frontend, Backend, and Database) with one command:

```bash
chmod +x deploy.sh
./deploy.sh
```

- **Frontend**: http://localhost:5173
- **Backend API**: http://localhost:5001

## 🛠️ Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, Zustand
- **Backend**: Node.js, Express, MongoDB
- **DevOps**: Docker, Docker Compose, GitHub Actions

## ☁️ AWS Deployment Ready
This project includes:
- `Dockerfile` for optimized production builds.
- `docker-compose.yml` for container orchestration.
- `.github/workflows/` for automated CI/CD.

## 💻 Local Development

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
